Section 01

Principles

Five rules shape every decision in this system. When a new component is unclear, check it against these first.

01

Collage, not fintech

Layer stickers over type and let color bands carry the structure. Avoid polished dashboard chrome.

Source

02

Outline, never shadow

Every container uses a 1px black outline. No box-shadows, no gradients, no divider lines. Depth comes from color and overlap.

Rule

03

Loud display, quiet UI

Display type can reach 640px. UI text stays between 12px and 16px, in two weights only: 500 and 700.

Source

04

Color is structure

Sections change by band color: Sky Wash, then Paper White, then Concrete Gray. The six sticker colors are used together, with no single accent.

Source

05

Pill for action, soft for content

Navigation, buttons and tags are pills. Cards and panels use 20px to 40px radii. Nothing is squared off.

Source

06

Comfortable and touchable

Targets are at least 44px. Density stays comfortable, not compact, so the collage can breathe on touch screens.

Proposed

Source conflicts and resolutions

The Refero spec contradicts itself in eleven places. Each row records what it said, what this system does, and why.

#IssueSource saysResolution
1Filled CTA radiusComponent table: 40px. Pill rule: 1600px.Buttons are pills (1600px). The 40px value is not used for buttons.
